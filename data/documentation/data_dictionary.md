# Data Dictionary

## 1. Purpose

This document defines the variables used in datasets analysed by the project.

A separate data dictionary may be created for each major dataset where the variables differ substantially.

## 2. Variable Documentation

For each variable, record:

| Field | Description |
|---|---|
| Variable name | Exact column name in the dataset |
| Definition | What the variable measures |
| Data type | Text, integer, decimal, date or category |
| Unit | For example, minutes, pounds or percentage |
| Source | Original dataset and publisher |
| Missing values | How missing information is represented |
| Limitations | Known issues affecting interpretation |

## 3. Economic Variables

Potential variables may include:

- Implementation expenditure.
- Licensing expenditure.
- Staff time.
- Training expenditure.
- Maintenance expenditure.
- Number of tasks completed.
- Service capacity.
- Waiting time.
- Resource utilisation.
- Relevant clinical outcomes.

These variables will only be included where appropriate evidence is available.

## 4. Consistency

Variables with similar names must not automatically be assumed to measure the same concept.

Definitions, units, time periods and collection methods must be checked before combining observations from different sources.

## 5. Missing Information

Missing values will be identified and documented.

They will not automatically be replaced with zero or another assumed value.
